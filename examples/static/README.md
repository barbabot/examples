# Static Example

This is a simple example demonstrating the [static mode of Inalia](https://docs.inalia.app/static-mode) using the [Inalia addon for Slidev](https://github.com/Inalia-App/slidev-addon-inalia).

## Usage

1. Start the Slidev development server.
2. Open your browser and navigate to the presentation URL. Every data will be present and no requests will be made to inalia.app.

This mode is primarily useful to host presentations after they have been done.
