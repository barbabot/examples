# Basic Example

This is a simple example demonstrating how to use the [Inalia addon for Slidev](https://github.com/Inalia-App/slidev-addon-inalia) within a Slidev presentation.

## Usage

1. Create a new Talk in your Inalia account.
2. [Configure the environment variables](https://docs.inalia.app/environment-variables) for your Talk as described in the Inalia documentation.
3. Start the Slidev development server.

Enjoy your presentation! 🎊
